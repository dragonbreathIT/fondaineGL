# Downloaded assets

Run `node tools/fetch-assets.mjs` (scanned textures / models) and `node tools/fetch-sounds.mjs` (recorded sounds → `sounds/`) to fill this folder (see README → Scanned assets → Recorded sounds). `manifest.json` registers everything, `CREDITS.md` lists title / author / licence / link per file (CC0 and CC-BY only). `.cache/` holds the raw downloads and can be deleted. Nothing here is committed.
